# [2026-09-02 19:08] ЕПК и комбинаторные объявления через v501

## Что сделано

- Обновлён upstream до версии 1.2.0: он поддерживает самостоятельные кабинеты через `YD_DIRECT_TOKENS` и даёт read-only проверку доступных кабинетов.
- Добавлены `yd_unified_campaigns_add`, `yd_unified_adgroups_add` и `yd_responsive_ads_add` для актуального API v501.
- Добавлены офлайн-проверки payload: микрорубли для бюджета, отключение РСЯ для search-only кампании, обязательный `OfferRetargeting` и `ResponsiveAd`.

## Зачем

Старые инструменты создавали TextCampaign и TextAd, тогда как для новых ЕПК Директ использует v501 и комбинаторные объявления. Обратная совместимость со старыми инструментами сохранена.
